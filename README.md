# Mini App Shop 

Минимальный рабочий прототип интернет-магазина. Проект включает в себя Telegram-бота для администрирования товаров и Telegram Mini App (веб-каталог) для их просмотра.

## Стек технологий
*   **Frontend:** Next.js 15+ (App Router), React
*   **Backend:** FastAPI (Python 3.13), SQLAlchemy (async)
*   **Telegram Bot:** Aiogram 3.x
*   **База данных:** PostgreSQL 16
*   **S3 Хранилище:** MinIO
*   **Инфраструктура:** Docker Compose, Ngrok

## Функционал
1.  **Бот (Aiogram):**
    *   Команда `/start` с кнопкой открытия Telegram Mini App.
    *   Добавление товара администратором (отправка фото с подписью в одном сообщении).
    *   Загрузка фото в MinIO и сохранение записи в PostgreSQL.
2.  **Каталог (Next.js):**
    *   Отображение списка товаров с фотографиями.
    *   Удаление товаров (через прокси-роуты Next.js).
    *   Работает как в обычном браузере, так и внутри Telegram.
3.  **Бэкенд (FastAPI):**
    *   Асинхронная работа с PostgreSQL.
    *   Стриминг изображений из MinIO.
    *   Настроен CORS для работы с фронтендом.

## Архитектура и отказоустойчивость 
Главное требование — возможность запуска в нескольких инстансах (2+ реплики) — **выполнено**. Все сервисы спроектированы как **stateless**:
*   **FastAPI** не хранит состояние в оперативной памяти. Все данные (товары) сохраняются в PostgreSQL.
*   **Файлы (картинки)** не сохраняются на локальный диск контейнера. Бот скачивает фото из Telegram и отправляет в FastAPI, который, в свою очередь, загружает его в объектное хранилище MinIO. Это позволяет любому инстансу бэкенда прочитать картинку.
*   **Next.js** использует прокси-роуты (API Routes) для обращения к FastAPI. Это решает проблемы с CORS и позволяет безопасно передавать данные.
*   **Бот** работает без хранения состояния в памяти (нет FSM, которые могли бы потеряться при перезапуске).

## Особенности реализации
* Реализована проверка на "ADMIN_ID". Админ отправляет фото с подписью одним сообщением. Бот перехватывает "photo" и "caption", скачивает файл и отправляет через "httpx" на бэкенд.
* Для обхода ограничения Telegram (запрет на "http://" ссылки) использован Ngrok. Сайт адаптирован под мобильные устройства и корректно открывается внутри Telegram.
* Для отдачи картинок из MinIO через Next.js используется стриминг ("ReadableStream"). Это позволяет избежать загрузки тяжелых файлов в оперативную память сервера и корректно отображать картинки внутри Telegram.

## Инструкция по локальному запуску

**1. Требования**

Для запуска проекта необходимы:

- Docker и Docker Desktop
- Python 3.12+
- Node.js 18+
- Аккаунт Ngrok (для HTTPS-ссылки для Telegram Mini App)

**2. Настройка окружения**

Создайте файл `.env` в корне проекта и добавьте туда токен вашего Telegram-бота:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

**3. Запуск инфраструктуры (БД и MinIO)**

В корне проекта выполните:

```bash
docker compose up -d
```

В MinIO (панель управления `http://localhost:9001`, логин/пароль: `minioadmin`) нужно вручную создать бакет с названием `basket`.

**4. Запуск Бэкенда (FastAPI)**

Откройте терминал и выполните:

```bash
cd backend
python -m venv venv
```

**Windows:**

```bash
venv\Scripts\activate
```

**Mac/Linux:**

```bash
source venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите сервер:

```bash
uvicorn main:app --reload
```

API доступно по адресу `http://localhost:8000`.

**5. Запуск Фронтенда (Next.js)**

Откройте новый терминал:

```bash
cd frontend
npm install
npm run dev -- -H 0.0.0.0
```

Сайт доступен по адресу `http://localhost:3000`.

**6. Запуск Бота (Aiogram)**

Откройте новый терминал:

```bash
cd bot
python -m venv venv
```

**Windows:**

```bash
venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите бота:

```bash
python bot.py
```
